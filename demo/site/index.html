These prices come from the same feed as the market tools your agents call. The sources are CoinGecko and the alternative.me Fear & Greed index, and the data is refreshed every minute.

Everything an agent needs to spend and earn

Sign in with MetaMask, Rabby, Coinbase Wallet, Phantom or any EIP-6963 / Solana wallet. You don't need an email or a password.

◎

Agent wallets

Generate EVM or Solana keypairs in your browser, or register an address you already have. Private keys never leave the page. The console shows live ETH, SOL and USDC balances on Base, Ethereum, Solana and their testnets.

⇄

x402 paywalls

Put any HTTPS API behind a pay-per-request URL priced in USDC. Callers get an HTTP 402 with payment requirements, sign an EIP-3009 authorization and get the response. Payments are verified and settled through the x402.org facilitator.

↗

Pay console

Paste any x402 URL to see its price and accepted networks. Pay with an agent key or your connected wallet and inspect the response and the on-chain transaction. Speaks both x402 v1 and v2.

▤

59 market tools

Prices, OHLC, trending coins, DeFi TVL, yields, gas, DEX pairs, Fear & Greed and more from the @agenti/market catalog. Each tool has a generated form, and its input is validated against the same Zod schema the agent sees.

⌁

MCP endpoint

Point Claude, Cursor or any MCP client at /mcp with an API key. You get every market tool plus wallet balances, x402 inspection and your paywalls and agent wallets.

⚿

API keys & usage

Create scoped sk_agenti_… keys for agents and servers, then revoke them at any time. Each call is logged with its route and latency so you can see exactly what your agents did.

From zero to a paid API call in four steps

Everything below runs on Base Sepolia with test USDC. You can get test USDC for free from the Circle faucet.

1. Sign in

Connect a wallet and sign one message (SIWE or SIWS). Your session lasts 30 days.

2. Fund an agent

Generate an agent wallet and send it test USDC from faucet.circle.com. Its balance shows up live.

3. Publish a paywall

Wrap an HTTPS endpoint, set a price such as 0.01 USDC and get a public /x/… URL.

4. Pay for it

Paste the URL into the pay console, sign and read the response. The settlement shows on Basescan, and your paywall's earnings update.

Built for agents, not dashboards

The console and the API run on the same routes. Create a key under API keys and call the routes from anywhere.

  • POST /api/market/run/:tool runs any of the 59 market tools
  • GET /api/balances?address=… returns native and USDC balances
  • POST /api/pay/quote and /api/pay/submit inspect an x402 resource and pay for it
  • POST /mcp is a stateless MCP over Streamable HTTP (JSON-RPC)
  • /x/:id is your public x402 paywall
# Run a market tool
curl -s -X POST https://agenti.ninabrekkerese.workers.dev/api/market/run/get_price \
  -H "authorization: Bearer $AGENTI_KEY" \
  -H "content-type: application/json" \
  -d '{"ids":"bitcoin,ethereum"}'

# Add Agenti to an MCP client (mcp.json)
{
  "mcpServers": {
    "agenti": {
      "url": "https://agenti.ninabrekkerese.workers.dev/mcp",
      "headers": { "Authorization": "Bearer sk_agenti_…" }
    }
  }
}
